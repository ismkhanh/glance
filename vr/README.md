# Glance VR: Quest app

This folder is the Quest app (`headset/`, Godot 4.7.2) and its scripts: `build.sh` (build the APK), `cable.sh`
(install over USB), `package.sh` (one-folder release zip) and two double-click starters.

Setup, gestures, building and how it works: see the [main README](../README.md). The short version for the release
zip is [SETUP.md](SETUP.md).
